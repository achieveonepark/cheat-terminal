---
title: "치트 HUD"
---

터미널에 등록한 치트를 **화면 전체를 덮는 UI Toolkit HUD** 로 바로 실행할 수 있습니다.
명령을 등록하기만 하면 HUD 에 자동으로 등록·표시되므로 별도 작업은 없습니다.

## 열기

| 제스처 | 동작 | 에디터/데스크톱 |
| --- | --- | --- |
| **세 손가락 동시 탭 3회** | 치트 HUD 열기 / 닫기 | `F1` / `F10` |
| **네 손가락 동시 탭 3회** | 우상단 `Terminal / F2` 핸들 표시 / 숨김 | `F9` |
| 핸들 탭 | 콘솔 열기 / 닫기 | `F2` / `` ` `` |

에디터에서는 `Tools > Cheat Terminal` 메뉴로도 열 수 있습니다. 게임 뷰가 포커스를 잃어
키 입력이 게임까지 도달하지 않을 때 쓰세요.

```csharp
using Achieve.CheatTerminal;

TerminalBehaviour.OpenCheatHud();
TerminalBehaviour.CloseCheatHud();
TerminalBehaviour.ToggleCheatHud();
```

## 레이아웃

- HUD 는 기본적으로 **화면 전체**를 덮습니다. 행 하나가 손가락으로 누르기 충분한 크기(최소 104px)이고,
  글자도 그에 맞게 큽니다.
- 노치 / 홈 인디케이터를 피하도록 `Screen.safeArea` 만큼 안쪽으로 패딩이 잡힙니다.
- 화면이 넓으면(가로 모드, 태블릿, 에디터 게임 뷰) 목록이 자동으로 2~3열로 나뉩니다.
- 하단 상태 줄에 큰 `CLOSE` 버튼이 있습니다. 세로로 긴 화면에서 상단 `X` 까지 손이 닿지 않을 때 쓰세요.
- 예전처럼 좌측에서 슬라이드되는 좁은 패널이 필요하면 전체 화면을 끕니다.

```csharp
TerminalBehaviour.CheatHudFullScreen = false;           // 좌측 슬라이드 패널로
TerminalBehaviour.Instance.CheatHud.WidthPercent = 42f; // 그때의 폭(%)
```

## 열기 / 닫기 리스너

HUD 나 콘솔이 열려도 게임은 계속 돌아갑니다. 열림/닫힘을 구독해서 `Time.timeScale` 을 낮추거나
입력을 막는 식으로 처리하세요.

```csharp
// 콘솔·치트 HUD 중 하나라도 열리면 true, 둘 다 닫히면 false
TerminalBehaviour.VisibilityChanged += open => Time.timeScale = open ? 0.2f : 1f;

// 각각 따로 받고 싶을 때
TerminalBehaviour.CheatHudVisibilityChanged += open => { /* ... */ };
TerminalBehaviour.ConsoleVisibilityChanged  += open => { /* ... */ };
```

시간만 멈추면 되는 경우는 한 줄로 끝납니다. 열릴 때의 `Time.timeScale` 을 저장했다가 닫힐 때
그대로 되돌립니다.

```csharp
TerminalBehaviour.PauseGameWhileOpen = true; // 열려 있는 동안 timeScale 고정
TerminalBehaviour.PausedTimeScale = 0f;      // 기본값 0 (완전 정지)
```

<Callout type="info">
  구독 해제는 `-=` 로 합니다. `CheatHudView.OnOpened` / `OnClosed` / `OnVisibilityChanged`,
  `UGuiTerminalView` 의 같은 이름 이벤트로 뷰에서 직접 받을 수도 있습니다.
</Callout>

## 표시 규칙

- 명령은 `category` 별로 묶여 표시되고, `System` 카테고리(내장 명령)는 항상 맨 뒤로 정렬됩니다.
- 상단 검색창에서 이름 / 설명 / 카테고리로 필터링합니다.
- `usage` 문자열이 실행 방식을 결정합니다.

| usage | HUD 동작 |
| --- | --- |
| `god` (인자 없음) | Run 버튼으로 실행 |
| `gold <amount>` | amount 입력 후 Run |
| `heal [amount]` | amount를 비우거나 입력한 뒤 Run |

```csharp
// 원터치 치트: usage 에 <>, [] 를 쓰지 않습니다.
TerminalBehaviour.RegisterCommand("god", ToggleGod, "무적 토글", "Cheats", "god");

// 인자 입력 치트
TerminalBehaviour.RegisterCommand("gold", AddGold, "골드 추가", "Cheats", "gold <amount>");
```

## 동작 방식

- HUD 는 `Terminal.Registry.Changed` 를 구독하므로, 런타임에 명령을 추가/제거해도 목록이 갱신됩니다.
- 실행 결과는 터미널 콘솔 출력과 HUD 하단 상태 줄에 함께 표시됩니다.
- 닫혀 있을 때는 패널이 `display: none` 이라 렌더링·레이아웃 비용이 없고,
  루트 요소는 입력을 가로채지 않으므로 게임 조작에 영향을 주지 않습니다.
- 헤더의 `Terminal / F2` 버튼으로 전체 터미널 콘솔을 열 수 있습니다.

## 도크와 단축키

에디터와 개발 빌드에서는 씬 로드 후 자동으로 부트스트랩됩니다. 우상단 도크의 슬라이더 아이콘은 Cheat Library, 터미널 아이콘은 Terminal을 엽니다. 그립이나 아이콘을 드래그하면 안전 영역 안에서 도크를 옮길 수 있습니다.

`F1`은 Cheat Library, `F2`는 Terminal을 여닫습니다. `F10`도 치트 UI를 열고, `F9`는 도크 표시를 전환합니다. 백틱은 터미널을 열기만 하며 Escape는 현재 화면을 닫습니다.

## 파라미터 입력과 실행

파라미터 입력란은 항상 표시됩니다. 명령 이름 대신 값만 입력하고 Run 또는 Enter로 실행합니다. `<amount>`는 필수, `[amount]`는 선택이며, `<x> <y> <z>`는 좌표별 입력란을 만듭니다. `<on|off>`는 선택값 버튼도 제공합니다. 필수값은 모두 입력하고 선택값은 뒤에서부터 생략해야 합니다. `[args]`와 `<text...>`는 공백으로 구분한 여러 인자를 받으며, 공백이 포함된 한 값은 따옴표로 묶습니다.

카테고리 버튼과 검색으로 명령을 찾습니다. 입력값은 필터링, 화면 크기 변경과 다시 열기 후에도 유지됩니다. 결과와 오류는 카드, 하단 상태 줄과 터미널 출력에 표시됩니다. 다른 화면으로 전환하면 이전 화면은 닫힙니다.
