## 安装

在 Unity Package Manager 中选择 **Add package from git URL**:

```
https://github.com/achieveonepark/cheat-terminal.git
```

## 打开控制台

在编辑器和开发构建中，场景加载后会自动 bootstrap。平时屏幕上不显示任何内容，需要用**多点触控手势**唤出 UI。

```csharp
// Release 构建不会自动创建控制台，因此需要调用一次。
Achieve.CheatTerminal.TerminalBehaviour.Bootstrap();
```

| 操作 | 方法 | 编辑器 / 桌面 |
| --- | --- | --- |
| 显示 / 隐藏右上角 `>_` 手柄 | **四指同时点按 3 次** | `F9` |
| 打开 / 关闭作弊 HUD | **三指同时点按 3 次** | `F10`, `F2` |
| 打开 / 关闭控制台 | 点击 `>_` 手柄，或面板右上角 `X` | `F1`, `` ` `` |
| 执行命令 | 输入后按 Enter | |
| 上一条 / 下一条历史 | 上 / 下方向键 | |
| 帮助 | `help`, `help <category>`, `help <command>` | |

再次做同样的手势即可关闭。详情参见 [作弊 HUD](./usage/cheat-hud)。

## 在编辑器中使用

鼠标做不出多点触控手势，所以编辑器和桌面改用按键：`F1`（或反引号 `` ` ``）开关控制台，
`F10` 开关作弊 HUD，`F9` 开关右上角手柄。反引号只负责打开，因此在输入命令时不会误触。

当 Game 视图没有焦点时按键无法传到游戏，这时请使用菜单：

```
Tools > Cheat Terminal > Toggle Console
                       > Toggle Cheat HUD
                       > Toggle Corner Handle
                       > Pause Game While Open
```

<Callout type="info">
  没有 `EventSystem` 时 UI 无法点击。场景中若不存在，终端会自动创建；
  在仅使用 Input System 的项目中会附带 `InputSystemUIInputModule`。
</Callout>

## 通过代码控制

```csharp
using Achieve.CheatTerminal;

TerminalBehaviour.Open();        // 打开
TerminalBehaviour.Toggle();      // 切换
TerminalBehaviour.Execute("gold 100000"); // 直接执行命令

TerminalBehaviour.ToggleCheatHud();      // 切换作弊 HUD
TerminalBehaviour.HandleVisible = true;  // 显示右上角手柄

// 打开 / 关闭监听（控制台与作弊 HUD 合并）
TerminalBehaviour.VisibilityChanged += open => Time.timeScale = open ? 0.2f : 1f;
TerminalBehaviour.PauseGameWhileOpen = true; // 同样的处理，一行搞定
```
