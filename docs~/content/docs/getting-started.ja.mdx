## インストール

Unity Package Manager で **Add package from git URL** を選びます。

```
https://github.com/achieveonepark/cheat-terminal.git
```

## コンソールを開く

エディターと開発ビルドでは、シーン読み込み後に自動でブートストラップされます。右上のドックでスライダーのアイコンは Cheat Library、ターミナルのアイコンは Terminal を開きます。グリップやアイコンをドラッグすると、安全領域内でドックを移動できます。

```csharp
// リリースビルドでは自動生成されないため、一度だけ呼び出します。
Achieve.CheatTerminal.TerminalBehaviour.Bootstrap();
```

| 操作 | 方法 | エディター / デスクトップ |
| --- | --- | --- |
| 右上の `Terminal` ハンドルの表示 / 非表示 | **4 本指の同時タップ 3 回** | `F9` |
| チート HUD の開閉 | **3 本指の同時タップ 3 回** | `F1`, `F10` |
| コンソールの開閉 | `Terminal` ハンドル、またはパネル右上の `Close` をタップ | `F2`, `` ` `` |
| コマンド実行 | 入力して Enter | |
| 前 / 次の履歴 | 上 / 下矢印 | |
| ヘルプ | `help`, `help <category>`, `help <command>` | |

同じジェスチャーをもう一度行うと閉じます。詳細は [チート HUD](./usage/cheat-hud) を参照してください。

## エディターで使う

マウスではマルチタッチジェスチャーを出せないため、エディターとデスクトップではキーを使います。
`F1` は Cheat Library、`F2` は Terminal の開閉です。`F10` でもチート UI を開き、`F9` でドックの表示を切り替えます。バッククォートは Terminal を開くだけで、Escape は現在の画面を閉じます。

Game ビューがフォーカスされていないとキーはゲームに届きません。そのときはメニューを使います。

```
Tools > Cheat Terminal > Toggle Console
                       > Toggle Cheat HUD
                       > Toggle Corner Handle
                       > Pause Game While Open
```

<Callout type="info">
  `EventSystem` がないと UI はクリック・タップできません。シーンに無ければターミナルが作成し、
  Input System のみのプロジェクトでは `InputSystemUIInputModule` を付けて作ります。
</Callout>

## コードから制御

```csharp
using Achieve.CheatTerminal;

TerminalBehaviour.Open();        // 開く
TerminalBehaviour.Toggle();      // 切り替え
TerminalBehaviour.Execute("gold 100000"); // 直接実行

TerminalBehaviour.ToggleCheatHud();      // チート HUD を切り替え
TerminalBehaviour.HandleVisible = true;  // 右上ハンドルを表示

// 開閉リスナー（コンソールとチート HUD をまとめて）
TerminalBehaviour.VisibilityChanged += open => Time.timeScale = open ? 0.2f : 1f;
TerminalBehaviour.PauseGameWhileOpen = true; // 同じ処理を 1 行で
```


## パラメーターの入力と実行

パラメーター欄は常に表示されます。コマンド名ではなく値だけを入力し、Run または Enter で実行します。`<amount>` は必須、`[amount]` は任意、`<x> <y> <z>` は座標別の入力欄です。`<on|off>` は選択ボタンも表示します。必須欄はすべて入力し、任意欄は末尾から省略してください。`[args]` と `<text...>` は空白区切りの複数引数を受け取り、空白を含む一つの値は引用符で囲みます。

カテゴリーボタンと検索でコマンドを探せます。入力値は絞り込み、画面サイズの変更、再表示後も保持されます。結果やエラーはカード、下部のステータス行、Terminal に表示されます。別の画面を開くと前の画面は閉じます。
