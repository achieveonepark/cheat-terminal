## 콘솔 열기

에디터와 개발 빌드에서는 씬 로드 후 자동으로 부트스트랩됩니다. 우상단 도크의 슬라이더 아이콘은 Cheat Library, 터미널 아이콘은 Terminal을 엽니다. 그립이나 아이콘을 드래그하면 안전 영역 안에서 도크를 옮길 수 있습니다.

```csharp
// 릴리즈 빌드에서는 자동 생성되지 않으므로 한 번 호출
Achieve.CheatTerminal.TerminalBehaviour.Bootstrap();
```

| 동작 | 방법 | 에디터/데스크톱 |
| --- | --- | --- |
| 우상단 `Terminal` 핸들 표시 / 숨김 | **네 손가락 동시 탭 3회** | `F9` |
| 치트 HUD 열기 / 닫기 | **세 손가락 동시 탭 3회** | `F1`, `F10` |
| 콘솔 열기 / 닫기 | `Terminal` 핸들 탭, 또는 패널 우상단 `Close` | `F2`, `` ` `` |
| 명령 실행 | 입력 후 Enter | |
| 이전/다음 기록 | 위 / 아래 화살표 | |
| 도움말 | `help`, `help <카테고리>`, `help <명령>` | |

같은 제스처를 다시 하면 닫힙니다. 자세한 내용은 [치트 HUD](./usage/cheat-hud) 를 참고하세요.

## 에디터에서 쓰기

마우스로는 멀티터치 제스처를 낼 수 없으므로, 에디터·데스크톱에서는 키를 씁니다.
`F1`은 Cheat Library, `F2`는 Terminal을 여닫습니다. `F10`도 치트 UI를 열고, `F9`는 도크 표시를 전환합니다. 백틱은 터미널을 열기만 하며 Escape는 현재 화면을 닫습니다.

게임 뷰가 포커스를 잃으면 키 입력이 게임까지 도달하지 않습니다. 그때는 메뉴를 쓰세요.

```
Tools > Cheat Terminal > Toggle Console
                       > Toggle Cheat HUD
                       > Toggle Corner Handle
                       > Pause Game While Open
```

<Callout type="info">
  UI 는 `EventSystem` 이 있어야 클릭·탭이 됩니다. 씬에 하나도 없으면 터미널이 직접 만들며,
  Input System 전용 프로젝트에서는 `InputSystemUIInputModule` 을 붙여서 생성합니다.
</Callout>

## 코드로 제어

```csharp
using Achieve.CheatTerminal;

TerminalBehaviour.Open();        // 열기
TerminalBehaviour.Toggle();      // 토글
TerminalBehaviour.Execute("gold 100000"); // 명령 직접 실행

TerminalBehaviour.ToggleCheatHud();      // 치트 HUD 토글
TerminalBehaviour.HandleVisible = true;  // 우상단 핸들 표시

// 열림 / 닫힘 리스너 (콘솔·HUD 통합)
TerminalBehaviour.VisibilityChanged += open => Time.timeScale = open ? 0.2f : 1f;
TerminalBehaviour.PauseGameWhileOpen = true; // 위와 같은 처리를 한 줄로
```


## 파라미터 입력과 실행

파라미터 입력란은 항상 표시됩니다. 명령 이름 대신 값만 입력하고 Run 또는 Enter로 실행합니다. `<amount>`는 필수, `[amount]`는 선택이며, `<x> <y> <z>`는 좌표별 입력란을 만듭니다. `<on|off>`는 선택값 버튼도 제공합니다. 필수값은 모두 입력하고 선택값은 뒤에서부터 생략해야 합니다. `[args]`와 `<text...>`는 공백으로 구분한 여러 인자를 받으며, 공백이 포함된 한 값은 따옴표로 묶습니다.

카테고리 버튼과 검색으로 명령을 찾습니다. 입력값은 필터링, 화면 크기 변경과 다시 열기 후에도 유지됩니다. 결과와 오류는 카드, 하단 상태 줄과 터미널 출력에 표시됩니다. 다른 화면으로 전환하면 이전 화면은 닫힙니다.
