## Installation

In Unity Package Manager, choose **Add package from git URL**:

```
https://github.com/achieveonepark/cheat-terminal.git
```

## Opening the console

The terminal bootstraps automatically in the editor and development builds. A developer dock is visible at the top right: the sliders icon opens Cheat Library and the terminal icon opens Terminal. Drag the grip or either icon to move the dock within the safe area.

```csharp
// Release builds do not auto-create the console, so call this once.
Achieve.CheatTerminal.TerminalBehaviour.Bootstrap();
```

| Action | How | Editor / desktop |
| --- | --- | --- |
| Show / hide the top-right `Terminal` handle | **Tap with 4 fingers, 3 times** | `F9` |
| Open / close the cheat HUD | **Tap with 3 fingers, 3 times** | `F1`, `F10` |
| Open / close the console | Tap the `Terminal` handle, or the panel `Close` | `F2`, `` ` `` |
| Run a command | Type and press Enter | |
| Previous / next history | Up / Down arrow | |
| Help | `help`, `help <category>`, `help <command>` | |

Repeating the same gesture closes it again. See [Cheat HUD](./usage/cheat-hud) for details.

## Using it in the editor

A mouse cannot produce a multi-touch gesture, so the editor and desktop use keys instead:
`F1` opens Cheat Library, `F2` opens Terminal, `F10` is another cheat shortcut, and `F9` toggles the dock. Backquote only opens Terminal; Escape closes the active surface.

When the Game view does not have focus the keys never reach the game. Use the menu then:

```
Tools > Cheat Terminal > Toggle Console
                       > Toggle Cheat HUD
                       > Toggle Corner Handle
                       > Pause Game While Open
```

<Callout type="info">
  Nothing is clickable without an `EventSystem`. If the scene has none, the terminal creates
  one - with `InputSystemUIInputModule` in Input System-only projects.
</Callout>

## Control from code

```csharp
using Achieve.CheatTerminal;

TerminalBehaviour.Open();        // Open
TerminalBehaviour.Toggle();      // Toggle
TerminalBehaviour.Execute("gold 100000"); // Execute directly

TerminalBehaviour.ToggleCheatHud();      // Toggle the cheat HUD
TerminalBehaviour.HandleVisible = true;  // Show the top-right handle

// Open / close listener (console and cheat HUD combined)
TerminalBehaviour.VisibilityChanged += open => Time.timeScale = open ? 0.2f : 1f;
TerminalBehaviour.PauseGameWhileOpen = true; // the same thing, in one line
```


## Parameter forms and execution

Parameter fields are always visible. Enter values and press Run or Enter; you never need to type the command name. `<amount>` is required, `[amount]` is optional, `<x> <y> <z>` creates separate coordinate fields, and `<on|off>` adds choice buttons. Required fields must be filled. Optional fields can be omitted from the end, without gaps. `[args]` and `<text...>` accept several space-separated arguments; quote a single value that contains spaces.

Use category buttons and search to find commands. Values survive filtering, resizing and reopening. Results and errors appear on the card, bottom status bar and terminal output. Switching surfaces closes the previous surface.
